### 1.6a 随机刷题专项（一期改造）

> **产品边界**  
> - **备考设置 `subjectSelection`**：用户考哪些科 → **每日一练 + 随机刷题** 共用。  
> - **备考设置 `dailySubjectMode`**：仅 **每日一练**（fixed / random 科目），与随机刷题无关。  
> - **随机科目筛选 `randomSubjectFilter`**：仅 **随机刷题**（全随机 / 指定一科），存 `user_exam_preference`，与每日一练模式独立；**仅在刷题面板「自定义范围」配置**，备考弹窗不展示。  
> - **随机刷题 UI**：不展示「连续打卡」；打卡 streak 仅主页每日一练语义。  
> - **默认行为**：完成备考后随机刷题默认 `all`（全随机）；用户可在刷题模块改为 `single` 指定科目。

#### 设计决策（已确认）

| 议题 | 决策 |
|------|------|
| 调度层 vs 错题本 | **双轨**：`user_question_record` 自动更新（出题池）；错题本 **仅用户点「加入错题本」** 时写入 |
| 随机偏好存储 | 扩展 `user_exam_preference`：`random_subject_mode`（`all`/`single`）+ `random_subject`；`localStorage` 仅未登录兜底 |
| 科目切换 | **筛选变、记录留**：`user_question_record` 按用户×题目长期保留；换科/换筛选只改「今日从哪一科抽」，不删记录 |
| 今日已做 | **按日 + 按科**：Redis `ul:practice:random:done:{userId}:{yyyyMMdd}:{subject}`；换天重计 |
| 备考科目变更 | 超出新备考范围的记录 **保留但不参与出题** |
| 考试科目 → 题库科目 | 后端维护映射（与前端 `examSubjects.ts` 对齐），`random` 以用户备考为准，不信任前端随意传参 |

#### 选题池组装（`GET /random`）

```text
1. 读用户备考科目 → 映射题库 subject 列表 S
2. 读 randomSubjectFilter → 今日科目子集 T（T ⊆ S）
   · all：T = S（在用户全部备考映射科目中混合抽）
   · single：T = { random_subject }（须在 S 内）
3. 候选题 question WHERE subject IN T
4. 排除今日已做（source=random，按科 Redis Set）
5. 关联 user_question_record 分池（仅 subject ∈ T）：
   · WRONG           → 高权重（无视旧 next_review_time）
   · RIGHT 且 now >= next_review_time → 中权重
   · NEW（无记录）   → 低权重
6. 加权随机抽一题（WRONG ×3、复习 ×1、NEW ×1，可二期调参）
```

答对间隔：`2 → 4 → 7 → 14 → …` 天；再次做错打回 `WRONG` 并重置间隔。详见 [随机刷题选题原理](./随机刷题选题原理.md)。

#### 科目筛选切换场景

| 场景 | 行为 |
|------|------|
| 今天刷数学，明天换计算机 | 明天只从计算机池抽；数学 WRONG/RIGHT 记录 **保留**；切回数学标签继续数学池；数学「今日已做」明天从 0 计 |
| 今天全随机，明天指定高等数学 | 明天只从高数池抽；其它科记录 **保留**；英语 WRONG 在 `all` 或选英语时再出现 |
| UI 提示 | 科目标签旁提示：「其它科目仍有待复习错题，切换标签可继续」 |

### 1.7a 控制台 UI 联调检查清单（反复踩坑 · 必查）

> **背景**：备考设置 Dialog、随机刷题顶栏、主页每日一练等 Stitch 玻璃态 UI 在联调中多次返工。后续凡改 `el-dialog` / `el-drawer` / `el-overlay` / 面板切换，**按本表自测后再关单**。  
> 涉及文件：`stitch-overlays.css`、`ExamSettingsDialog.vue`、`PracticePanel.vue`、`ConsoleView.vue`、`DashboardPanel.vue`。

| # | 现象 | 根因 | 正确做法 |
|---|------|------|----------|
| U1 | 整页灰蒙蒙、按钮点不动 | `.el-overlay-dialog` 误当全屏遮罩上色 | 遮罩用 `.el-overlay`；备考专用 `modal-class="exam-settings-overlay"` |
| U2 | 备考弹窗偏下 / 偏左 | `align-center` 与自定义 `margin`、flex 居中冲突 | 去掉 `align-center`；`.el-overlay-dialog` 顶部对齐 `align-items: flex-start` |
| U3 | 弹窗未选专业时大块空白 | `height: 100%` / `flex:1` 撑满 overlay | Dialog `height: fit-content`；内容区勿无意义 `flex:1` |
| U4 | 展开时文字挤压、卡顿 | `max-height` + `translateY` 叠在文字容器上 | 高度用 `grid-template-rows: 0fr→1fr`；**文字不做位移**；提示区仅 `opacity` 淡出 |
| U5 | 淡出完才下拉，中间空等 | `transition-delay` 串行等待 | 提示 `leave` 时 `position:absolute` 脱离文档流；与下拉**同时**执行、同曲线（约 0.48s） |
| U6 | 加载中改 hint 文案布局跳动 | 展开动画与接口返回改 DOM 重叠 | 科目规则**加载完成后再** `Transition` 展开；加载期单独占位行 |
| U7 | 切模块回主页丢解析/作答 | 业务面板 `v-if` 销毁子组件 | 控制台业务区用 `v-show`（`DashboardPanel` 等） |
| U8 | 备考已保存仍「暂无题目」 | `PracticePanel` 过早 `onMounted` 拉题失败不再重试 | `await loadRemote()`；监听 `isConfigured` + 路由 hash 自动 `fetchRandom` |
| U9 | 改备考后随机筛选被重置 | 备考 `patch`/`saveRemote` 写入 `randomSubjectMode` | 备考 PUT **仅** province/届别/科目/每日一练；随机筛选 **仅** `PUT /random-filter` |
| U10 | Dialog 样式两处维护不一致 | 组件内第二段 unscoped 与全局重复 | 外壳样式集中在 `stitch-overlays.css`；组件内只留 scoped 布局 |
| U11 | 侧栏拓展与主区宽度不同步 | 仅内容动、Dialog `width` 未过渡 | Dialog `width` 与侧栏同曲线 `cubic-bezier(0.4,0,0.2,1)` ~0.42s |

**动效约定（备考设置）**：右侧科目拓展 = `translateX` + `opacity`；下方科目区展开 = `grid-template-rows`；引导文案 = 仅 `opacity`（不折叠高度）。
