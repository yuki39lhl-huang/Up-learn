每个模块都有三个配置文件,分别是 application / application-dev / application-local。

- **application.yml**：端口、服务名、Nacos 地址、`spring.config.import`（拉配置清单）。业务项已外置到 **Nacos**。
- **application-dev.yml**：服务进 Docker（`ul-net`）时的主机名占位（`ul-mysql` 等）。
- **application-local.yml**：IDEA 本机端口 + **密钥**；勿提交真实 AccessKey / 邮箱授权码。

### Nacos 配置中心（§2.11）

仓库源文件：[`backend/nacos-config`](../backend/nacos-config/README.md)。

```powershell
powershell -ExecutionPolicy Bypass -File backend/nacos-config/publish.ps1
```

| DataId | 内容 |
|--------|------|
| `ul-common.yaml` | JWT、Redis/RabbitMQ 占位、日志 |
| `ul-datasource.yaml` | MySQL + MyBatis-Plus（仅带库服务） |
| `{service}.yaml` | 各服务业务配置 |

控制台：http://localhost:8088 （`nacos` / `nacos`）。改完仓库 yaml 后重新 publish，再重启服务。

## 阿里云 OSS（图片存储）

用户头像等图片走 **阿里云 OSS**，Bucket **`uplearn`**（华北2 北京 `oss-cn-beijing`）。  
AccessKey / Secret 仅写在各服务 `application-local.yml`（或环境变量），**勿提交 Git**；OSS 非密钥骨架在 Nacos `user-service.yaml`。建议本机字段：

```yaml
ul:
  oss:
    endpoint: oss-cn-beijing.aliyuncs.com
    bucket: uplearn
    public-base-url: https://uplearn.oss-cn-beijing.aliyuncs.com
    enabled: true
    # access-key-id / access-key-secret 本机填写（展示头像也需要密钥生成签名 URL）
```

库内存 canonical URL，接口返回 **presigned URL**（默认 2h）。本地若未填 AccessKey，已上传的 OSS 头像将无法显示（签名依赖密钥；上传另需 `enabled: true`）。

IDE 中 `ul.oss` 未知属性警告：由 `user-service` 的 `META-INF/additional-spring-configuration-metadata.json` 登记；刷新 Maven / Rebuild 后消失。

## QQ 邮箱验证码（SMTP）

发码仍：**同步写 Redis** → RabbitMQ 队列 `ul.login.code.dispatch` → 消费者发信；MQ 不可用则同步降级同一发信逻辑。

- `ul.login.dev-log-code: true`（Nacos `user-service.yaml` 默认）：只打日志，不发邮件。
- `false`：走 QQ SMTP（需配置 `spring.mail`）。

SMTP 骨架在 Nacos `user-service.yaml`（`smtp.qq.com:465` + SSL），**不含授权码**。本机在 `application-local.yml`：

```yaml
spring:
  mail:
    username: 你的QQ邮箱@qq.com
    password: QQ邮箱授权码   # 不是登录密码；勿提交 Git
ul:
  login:
    dev-log-code: false      # 本机真实发信时再关
    # 邮件 logo 用 OSS 公网图（默认 {public-base-url}/brand/logo-mark.png）
    # mail-logo-url: https://uplearn.oss-cn-beijing.aliyuncs.com/brand/logo-mark.png
```

需先把 `frontend/public/brand/logo-mark.png` 上传到桶路径 `brand/logo-mark.png`（公共读即可显示）。
