概念划分，给每道题打用户维度状态（用户‑题目关联表）
user_question_record
question_id
user_id
status：NEW(未做) / WRONG(做错) / RIGHT(答对)
last_answer_time：上次作答时间
next_review_time：建议下次复习时间（核心字段）
wrong_count：做错次数
right_count：做对次数
规则逻辑
同一天内：同一道题不会重复出现
不管对还是错，同一天随机池过滤掉今天已经答过的题目。
错题（status=WRONG）优先级最高
只要是错题，优先进入刷题池；
用户把错题答对：
status 改为RIGHT
清除错题标记，但不要直接删掉这条记录！
设置next_review_time，比如：2 天后再回来复习这道题
之前答对过的题 status=RIGHT，不是永久剔除
不在第二天立刻出现；
等到 now >= next_review_time，这道题重新回到随机候选池；
如果再次做对：拉长下次复习间隔（4 天→7 天……）
如果再次做错：变回 WRONG，重置复习间隔，优先刷它。
新题 status=NEW：题库剩余没做过的题目，作为兜底填充
边界细节处理
用户刷的时候，如果复习题再次答对：逐步拉长复习间隔：2 天 →4 天 →7 天 →14 天，超过比如 30 天可以标记为掌握，降低出现权重。
复习题再次做错：打回错题池，间隔重置，优先刷。
不要把复习题堆到同一天，next_review_time 分散，避免某一天题库爆炸。
随机的时候，错题权重更高：比如 shuffle 之前，错题放多份虚拟权重，随机抽到错题概率大于复习题、大于新题。
数据库关键点提醒
不要把错题仅仅存一个简单的错题 id 列表。
一定要用用户‑题目中间记录表，存储每道题的状态、上次作答、下次复习时间，才能实现间隔复习。单纯一张user_wrong_question只能实现你的最初版本，做不到已答对题复习。
now >= next_review_time 通俗解释
now：当前系统时间（用户现在点开随机刷题的这一刻）
next_review_time：这道题设置的允许下次拿出来复习的最早时间点
now >= next_review_time → 现在的时间，已经到了 / 超过了预定的复习时间，这道题可以重新放进刷题池给用户做。
举例子：
用户 8‑28 答对一道题，程序设置 next_review_time = 2026‑08‑30 00:00:00（2 天以后才允许复习）
8‑29 用户打开刷题：
now=2026‑08‑29，now < next_review_time
👉 时间还没到，这道题不出来，继续冷藏
8‑30 用户打开刷题：
now=2026‑08‑30，now >= next_review_time
👉 时间到期，这道题重新加入候选池，有机会被随机刷到。


2:提供不背单词的重温逻辑
不背单词复习规则（对照你专升本刷题平台做参考）
核心：间隔重复（spaced repetition），做对不会永久删掉，只是延后复习；做错大幅提前复习；用next_review_time控制什么时候重新进入任务池。
它和你最开始写的错误逻辑完全相反：
❌你最初版本：昨天答对 → 直接移出，永远不出现
✅不背单词：昨天答对 → 设置未来某个next_review_time；时间到了，重新进复习池
用户‑单词每条记录关键字段（类比你 user_question_record）
next_review_time：允许这道题再次出现的最早时刻
记忆状态 / 熟悉度：新词、模糊、掌握、顽固错题
做错次数、做对次数
用户操作三个反馈：认识 / 模糊 / 不认识
认识（答对）：拉长下次复习间隔，next_review_time往后推（2 天→4 天→7 天→14 天）
模糊：间隔小幅缩短，很快再来复习
不认识（做错）：间隔直接重置，优先级拉满，尽快再次出现，不受旧的 next_review_time 约束
每日任务池组装逻辑（Review 复习池）
plaintext
now = 当前打开APP的时间
候选 = 所有满足 now >= next_review_time 的单词
然后打乱，生成今天复习任务
还没到next_review_time：哪怕这道题你曾经做对，今天不会出来
一旦标记 “不认识”，直接覆盖 next_review_time，很快就会刷到
重点：同一天内，同一个单词不会重复推给你，防止同一回合反复刷同一题。
单词完整生命周期
新词：第一次学习，生成第一条记录，设置第一次next_review_time（比如 1 天后）
到复习时间，进入 Review 任务
答对：间隔变大，延后；
模糊：间隔略缩短；
做错：重置，短期内高频复习；
多次连续答对，间隔拉到很长，降低出现概率，但不会彻底删除记录，隔很久依然会回来抽检；
只有手动加入 “已掌握归档”，才不再参与复习。
和你专升本刷题平台的对照
你的刷题平台，完全可以照搬这套模型：
错题：无视旧 next_review_time，高优先级进池；
曾经答对的题：存入next_review_time，now >= next_review_time 才允许回到随机刷题池；
同一天作答过的题目，无论对错，当天不再出现；
用户再次答对，拉长间隔；再次做错，重置间隔。
区别点（背单词 vs 刷题）
单词 APP：复习题优先于新词，每天先刷复习任务，再学新词；
你的刷题平台：可以做成混合池：【错题 > 到期复习旧题 > 新题】，然后整体 shuffle 随机。
踩坑提醒（很多刷题系统做错这里）
不要：答对 → 删除记录，彻底不再出现（就是你最开始遇到的业务缺陷）。
要：答对 → 更新 next_review_time，冷藏一段时间，到期再回来。
