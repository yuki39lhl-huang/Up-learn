# 2024年广东省专升本《经济学》真题答案与解析

## 一、单项选择题（每题1分，共15分）

**1. 需求弹性最大的是（ ）**
**答案：B（手机）**
**解析：** 需求弹性大小与商品必需程度、替代品多少有关。大米、食盐是生活必需品，需求弹性小；手机属于耐用消费品，替代品多，需求弹性较大。

**2. D=7-p，S=3+p，当均衡时，p等于多少（ ）**
**答案：p=2**
**解析：** 均衡时 D=S，即 7-p=3+p，解得 4=2p，p=2。此时均衡数量 Q=5。

**3. 当消费者收入和商品价格既定，消费者收入全部用于消费可以购买到的两种商品的不同组合，这个曲线是（ ）**
**答案：C（预算约束线）**
**解析：** 预算约束线表示在收入和商品价格既定时，消费者全部收入所能购买到的两种商品各种数量组合。等成本线用于厂商生产，等产量线表示生产同一产量的要素组合。

## 四、名词解释（每题4分，共16分）

**36. 规模经济**
**答案：** 规模经济是指由于生产规模扩大，长期平均成本下降，产量增加的比例大于成本增加的比例，从而获得递增的规模报酬。

**37. 投资乘数**
**答案：** 投资乘数是指国民收入变动量与引起这种变动的投资变动量之间的比率，即 k=1/(1-MPC)=1/MPS。

**38. 生产者剩余**
**答案：** 生产者剩余是指厂商实际得到的价格总额与愿意接受的最低价格总额之间的差额，在图形上表现为供给曲线以上、市场价格以下的面积。

**39. 消费价格指数**
**答案：** 消费价格指数（CPI）是衡量一定时期内居民消费价格水平变动的相对数，通常用一篮子消费品和服务的价格加权计算。

## 五、简答题（每题8分，共24分）

**40. 简述经济周期及其特征。**
**答案：**
经济周期是指经济活动沿着总体趋势所经历的扩张与收缩交替更迭、循环往复的过程。一般分为繁荣、衰退、萧条、复苏四个阶段。
特征：
（1）繁荣阶段：生产增长、就业增加、物价上升、投资活跃。
（2）衰退阶段：经济下滑、需求下降、失业增加。
（3）萧条阶段：严重衰退、大量失业、企业破产。
（4）复苏阶段：经济回升、就业和投资逐步恢复。

**41. 市场有什么类型，其分类依据是什么？**
**答案：**
市场类型：完全竞争市场、垄断竞争市场、寡头垄断市场、完全垄断市场。
分类依据：
（1）厂商数目；
（2）产品差别程度；
（3）厂商对价格的控制程度；
（4）进入或退出行业的难易程度。

**42. 中央银行调节货币供给量的三大工具。**
**答案：**
（1）法定存款准备金率；
（2）再贴现率；
（3）公开市场业务。

## 六、材料分析题（15分）

**43. 材料一和材料二讲科技进步和收入增加（其中材料一讲彩电，材料二讲电脑），材料三是关于人工智能的。**

**（1）影响商品供给量的主要因素有哪些？**
**答案：**
商品自身价格、生产成本（要素价格）、生产技术、相关商品价格、厂商预期、厂商数量、政府政策等。

**（2）画图利用供求规律分析彩电均衡价格和数量的变化。**
**答案：**
科技进步使彩电生产成本下降，供给曲线向右移动；收入增加可能使需求曲线向右移动。若供给增加幅度大于需求增加幅度，均衡数量增加，均衡价格下降；若需求增加幅度更大，则价格可能上升。通常彩电行业技术进步快，供给大幅增加，价格趋于下降，数量增加。

**（3）在未来人工智能是否能进入百姓家？为什么？**
**答案：**
能。原因：
①技术进步使人工智能产品生产成本下降，供给增加；
②居民收入提高，需求增加；
③人工智能产品逐渐成为生活必需品或常用品，需求弹性较大；
④供求规律作用下，价格下降，需求增加，最终普及进入百姓家。

# 2023年广东省专升本《经济学》真题答案与解析

## 一、单项选择题（每题1分，共15分）

**1. 关于需求与供给的变动对均衡的影响，正确的是（ ）**
**答案：A**
**解析：** 供给不变，需求变动引起均衡价格与均衡数量同方向变动，A正确。需求不变，供给变动引起均衡价格与均衡数量反方向变动，B错。C、D方向描述错误。

**2. 经济分析中所说的短期指（ ）都随产量调整的时期。**
**答案：C**
**解析：** 短期指至少有一种生产要素不能随产量调整的时期；长期指全部生产要素都可以调整的时期。

**3. 某企业产量为100，边际成本为50，边际收益为50，其他条件不变，该企业（ ）**
**答案：D**
**解析：** 边际收益=边际成本=50，满足利润最大化条件，企业已经实现利润最大化，既不增加也不减少产量。

**4. 生产可能性曲线说明的基本原理是（ ）**
**答案：D**
**解析：** 生产可能性曲线表明在既定资源和技术条件下，只有减少一种物品的生产才能增加另一种物品的生产，体现资源稀缺性和机会成本。

**5. 如果某种商品的需求价格弹性是0.5，那么（ ）**
**答案：A**
**解析：** 需求价格弹性=需求量变动百分比/价格变动百分比。价格上升10%，需求量减少0.5×10%=5%。

**6. 总效用达到最大时（ ）**
**答案：B**
**解析：** 边际效用为零时，总效用达到最大；边际效用为正时总效用递增，为负时总效用递减。

**7. 经济学中的利润是指（ ）**
**答案：C**
**解析：** 经济学中的利润=总收益-经济成本，经济成本包括显性成本和隐性成本。

**8. 如果边际储蓄倾向为0.3，投资支出增加60亿元，将会使国民收入增加（ ）**
**答案：D**
**解析：** 投资乘数=1/MPS=1/0.3≈3.33，收入增加=60×3.33≈200亿元。

**9. 下列商品中不能通过“薄利多销”来增加收益的是（ ）**
**答案：A**
**解析：** 大米是生活必需品，需求弹性小，降价不能带来需求量的大幅增加，反而减少收益。

**10. 以下不属于宏观经济政策目标的是（ ）**
**答案：D**
**解析：** 宏观经济政策四大目标：充分就业、物价稳定、经济增长、国际收支平衡。汇率稳定不属于四大目标。

**11. 最需要进行广告宣传的市场是（ ）**
**答案：B**
**解析：** 垄断竞争市场产品有差别，厂商需要通过广告宣传吸引消费者。

**12. 披萨饼和炸玉米饼是替代品，如果披萨饼价格上升，则（ ）**
**答案：C**
**解析：** 替代品价格上升，消费者会转向另一种商品，炸玉米饼需求增加。

**13. 支出法核算该国GDP为（ ）**
**答案：B（6000亿元）**
**解析：** GDP=消费2000+投资3000+政府购买500+净出口(1000-500)=2000+3000+500+500=6000亿元。政府转移支付不计入GDP。

**14. 宏观经济学的核心是（ ）**
**答案：D**
**解析：** 宏观经济学核心是国民收入决定理论。

**15. 如果一国基尼系数变小，表明该国（ ）**
**答案：C**
**解析：** 基尼系数越小，收入分配越平等，不平等程度降低。

## 二、多项选择题（每题2分，共20分）

**16. 无差异曲线的特征包括（ ）**
**答案：BD**
**解析：** 无差异曲线一般具有负斜率，且坐标图上任意一点都应有一条无差异曲线通过。任意两条无差异曲线不能相交，一般凸向原点，不是正斜率。

**17. 用来衡量物价总水平变动的指数有（ ）**
**答案：BCD**
**解析：** 消费物价指数、生产物价指数、GDP平减指数均衡量物价总水平。股票价格指数不是。

**18. 关于AFC、AVC、AC三条曲线，说法正确的是（ ）**
**答案：ABCD**
**解析：** AFC随产量增加持续递减；AVC先递减后递增；AC先递减后递增；AC=AVC+AFC。

**19. 具有自动稳定器作用的政策包括（ ）**
**答案：ACD**
**解析：** 失业保障机制、所得税税收体系、农产品价格维持制度具有自动稳定器作用。国债发行制度不属于。

**20. 关于完全竞争下的厂商均衡，说法正确（ ）**
**答案：ABCD**
**解析：** 短期厂商不能调整全部生产要素；长期可以调整全部生产要素；短期供给小于需求时价格上升；长期供给小于需求时行业供给增加，价格下降。

**21. 超额利润的主要来源是（ ）**
**答案：BCD**
**解析：** 超额利润主要来源于创新、风险和垄断。劳动不是超额利润的直接来源。

**22. 中央银行增加货币供给的手段有（ ）**
**答案：ABC**
**解析：** 降低再贴现率、降低法定准备金率、公开市场买入国债均可增加货币供给。降低基础货币投放量会减少货币供给。

**23. 在其他条件不变的情况下，总供给曲线右移是因为（ ）**
**答案：AD**
**解析：** 技术进步和劳动需求增加可能使总供给增加，总供给曲线右移。所得税提高、原材料涨价会减少总供给。

**24. 根据凯恩斯的货币需求理论，当收入水平上升（ ）**
**答案：AC**
**解析：** 收入上升，交易动机和预防动机的货币需求增加；投机动机主要与利率有关。

**25. 以下应计入GDP的支出（ ）**
**答案：ABD**
**解析：** 家庭用于教育的支出属于消费；企业用于厂房的支出属于投资；政府用于修建道路的支出属于政府购买。政府用于社会保障的支出属于转移支付，不计入GDP。

## 三、判断题（每题1分，共10分）

**26. 当两种商品的需求交叉弹性<0时，这两种商品为互补品。**
**答案：正确**
**解析：** 交叉弹性为负，说明一种商品价格上升引起另一种商品需求减少，二者为互补品。

**27. 预算约束线是指在收入和商品价格既定的情况下，消费者用于全部收入所能购买到的各种商品不同数量的组合。**
**答案：正确**

**28. 在均衡等式 S+T=I+G 中，储蓄一定等于投资，税收一定等于政府支出。**
**答案：错误**
**解析：** 均衡等式表示总漏出等于总注入，不意味着储蓄一定等于投资、税收一定等于政府支出分别相等。

**29. 在宏观经济学中，总投资被定义为净投资减去折旧，总投资=净投资-折旧。**
**答案：错误**
**解析：** 总投资=净投资+折旧。

**30. 税收和政府转移支付都将由于对可支配收入的影响而影响消费。**
**答案：正确**

**31. 西方经济学一般把经济周期分为繁荣、发展、萧条、复苏等四个阶段。**
**答案：错误**
**解析：** 一般分为繁荣、衰退、萧条、复苏四个阶段，“发展”表述不准确。

**32. 厂商总成本不变，两种生产要素价格同比例上升，则等成本线向左下方平移。**
**答案：正确**
**解析：** 等成本线截距为 C/w 和 C/r，要素价格上升，截距变小，等成本线向左下方平移。

**33. 菲利普斯曲线表明失业率和通货膨胀之间存在正相关的关系。**
**答案：错误**
**解析：** 短期菲利普斯曲线表明失业率与通货膨胀率之间存在负相关关系。

**34. 假定土地没有自用价值，则土地的供给曲线与价格之间存在正向关系。**
**答案：错误**
**解析：** 土地供给固定，供给曲线垂直，与价格无关。

**35. 一位中国公民在英国拥有一处房地产用于出租，他赚取的租金是英国GDP的一部分同时也是中国GDP的一部分。**
**答案：错误**
**解析：** 该租金是英国GDP的一部分，是中国GNP的一部分，不是中国GDP。

## 四、名词解释（每题4分，共16分）

**36. 滞胀**
**答案：** 滞胀是指经济停滞与通货膨胀并存，即高失业率与高通货膨胀率同时出现的经济现象。

**37. 消费者剩余**
**答案：** 消费者剩余是指消费者愿意支付的价格总额与实际支付总额之间的差额。

**38. 寡头垄断**
**答案：** 寡头垄断是指少数几家厂商控制整个市场产品生产和销售的市场结构。

**39. 流动偏好陷阱**
**答案：** 流动偏好陷阱是指当利率极低时，人们预期利率不会再降，货币需求无限大，无论增加多少货币都被储存起来，货币政策失效。

## 五、简答题（每题8分，共24分）

**40. 影响需求量的主要因素？**
**答案：**
商品自身价格、消费者收入、相关商品价格、消费者偏好、消费者预期、人口数量与结构、政府政策等。

**41. 什么是边际报酬递减规律？边际报酬递减规律还适用于哪些情况？**
**答案：**
边际报酬递减规律：在技术不变、其他生产要素不变时，连续增加一种可变要素，起初边际产量增加，超过一定点后边际产量递减。
适用情况：短期生产函数、农业、工业生产等至少一种要素不变的情况。

**42. 有几种失业类型？形成的条件是什么？**
**答案：**
（1）摩擦性失业：劳动力流动、信息不完全导致。
（2）结构性失业：劳动者技能与岗位需求不匹配。
（3）周期性失业：总需求不足引起。
（4）季节性失业：季节变化引起。

## 六、材料分析题（15分）

**43. 材料：中央经济工作会议要求继续实施积极的财政政策和稳健的货币政策。**

**（1）实施积极的财政政策可采用哪些政策工具？**
**答案：**
增加政府支出、减税、增加转移支付、发行国债、扩大财政赤字等。

**（2）分析积极的财政政策对宏观经济指标如产出、价格水平、就业、投资、消费等产生的影响。**
**答案：**
积极财政政策扩大总需求，使产出增加、就业增加、消费增加；价格水平可能上升；投资可能因利率上升产生挤出效应，但总体扩张效应为主。

**（3）积极的财政政策和稳健的货币政策组合如何实现稳中求进。**
**答案：**
积极财政政策刺激需求，稳健货币政策保持流动性合理充裕，避免通胀和债务风险，二者协调配合，实现经济稳定增长和高质量发展。

# 2022年广东省专升本《经济学》真题答案与解析

## 一、单项选择题（每题1分，共15分）

**1. 经济学资源的稀缺性是指（ ）**
**答案：D**
**解析：** 资源稀缺性是指资源相对于人类无限欲望而言不足。

**2. 下列商品中需求弹性最小的是（ ）**
**答案：A（食盐）**
**解析：** 食盐是生活必需品，需求弹性最小。

**3. 当消费者购买数量为OM时，其消费者剩余是（ ）**
**答案：A（ANB）**
**解析：** 消费者剩余是需求曲线以下、价格线以上的面积，即三角形ANB。

**4. 短期内当平均产量曲线与边际产量曲线相交时（ ）**
**答案：D**
**解析：** 边际产量曲线与平均产量曲线相交于平均产量曲线的最高点。

**43. 材料一：疫情初期口罩需求激增，价格飞涨；政府复工后供给增加，价格平稳。材料二：煤炭价格上升，电价受限，电力供应减少，出现拉闸限电。**

## 五、简答题（每题8分，共24分）

**40. 生产者要增加销售收入，粮食和汽车应该涨价还是降价，原因是什么。**
**答案：**
粮食需求弹性小，应涨价，因为涨价不会使需求量大幅减少，总收入增加；汽车需求弹性大，应降价，薄利多销，需求量增加幅度大于价格下降幅度，总收入增加。

**41. 什么是GDP，怎样理解GDP？**
**答案：**
GDP是指一国或地区在一定时期内运用生产要素所生产的全部最终产品和劳务的市场价值。
理解：
（1）GDP是地域概念；
（2）只计算最终产品；
（3）用市场价值衡量；
（4）是一定时期内的流量。

**42. 简述凯恩斯的货币需求概念和动机。**
**答案：**
货币需求是指人们在不同条件下愿意持有的货币量。
动机：
（1）交易动机；
（2）预防动机；
（3）投机动机。

## 六、材料分析题（15分）

**43.**
**（1）失业有几种类型，他们的特点是什么。**
**答案：**
摩擦性失业：劳动力流动、信息不完全导致，短期性。
结构性失业：技能与岗位不匹配，长期性。
周期性失业：总需求不足引起，与经济周期相关。
季节性失业：季节变化引起，周期性明显。

**（2）根据边际技术替代率的相关知识，新时代的人工智能和智能技术会怎样影响企业的生产要素。**
**答案：**
边际技术替代率是指在产量不变时，增加一单位某种要素投入所减少的另一种要素投入量。人工智能和智能技术会替代劳动，改变资本与劳动组合，提高资本边际产量，降低劳动投入，企业更多使用资本和技术。

**（3）新时代我国怎样发展就业？**
**答案：**
发展经济扩大就业、鼓励创业、加强职业培训、完善社会保障、促进新业态发展、优化就业服务等。
