# 2024年山东省专升本《高等数学III》真题答案与解析

## 一、单项选择题（每题3分，共30分）

**1. 下列函数是奇函数的是（ ）**
**答案：B**
**解析：** \(x^3\) 为奇函数；\(\ln x\) 定义域不关于原点对称，\(\cos x\) 为偶函数，\(2^x\) 非奇非偶。

**2. 下列函数是周期函数的是（ ）**
**答案：C**
**解析：** \(\sin x\) 是周期函数。

**3. 当 \(x\to 0\) 时，以下函数是 \(x^2\) 的等价无穷小的是（ ）**
**答案：A**
**解析：** \(\sin^2 x \sim x^2\)；\(\sin 2x \sim 2x\)，\(\cos^2 x \to 1\)，\(e^{2x}-1 \sim 2x\)。

**4. 点 \(x=1\) 是函数 \(f(x)=\frac{x^2-2x}{x^2-3x+2}\) 的（ ）**
**答案：D**
**解析：** \(f(x)=\frac{x(x-2)}{(x-1)(x-2)}=\frac{x}{x-1}\)，\(x=1\) 为无穷间断点。

**5. 已知函数 \(y=f^2(5x)\)，则 \(dy=\)（ ）**
**答案：A**
**解析：** \(dy=2f(5x)\cdot f'(5x)\cdot 5dx=10f(5x)f'(5x)dx\)。

**6. 曲线 \(y=3x^5-5x^4+4x+2\) 的拐点是（ ）**
**答案：B**
**解析：** \(y''=60x^2(x-1)\)，在 \(x=1\) 处变号，\(y(1)=4\)，拐点为 \((1,4)\)。

**7. 已知 \(I_1=\int_{-1}^1\frac{\cos x}{1+x^2}dx\)，\(I_2=\int_{-1}^1\frac{\sin x}{1+x^2}dx\)，\(I_3=\int_{-1}^1\frac{1}{1+x^2}dx\)，则下列不等式成立的是（ ）**
**答案：D**
**解析：** \(I_2=0\)（奇函数），\(I_1\) 为偶函数且被积函数小于 \(\frac{1}{1+x^2}\)，故 \(0<I_1<I_3\)，即 \(I_2\le I_1\le I_3\)。

**8. \(\int_1^2\frac{1}{x}f\left(\frac{1}{x}\right)dx=\)（ ）**
**答案：A**
**解析：** 令 \(t=\frac{1}{x}\)，得 \(\int_{1/2}^1\frac{f(t)}{t}dt=\int_{1/2}^1\frac{f(x)}{x}dx\)。

**9. 已知 \(\int f(x)dx=e^{-3x}+C\)，则 \(xf(x)\) 的一个原函数为（ ）**
**答案：B**
**解析：** \(f(x)=-3e^{-3x}\)，\(\int xf(x)dx=\int -3xe^{-3x}dx=e^{-3x}\left(x+\frac13\right)+C\)。

**10. 已知 \(y=(3+2\cos x)^x\)，则 \(y'=\)（ ）**
**答案：C**
**解析：** 对数求导得 \(y'=(3+2\cos x)^x\left[\ln(3+2\cos x)-\frac{2x\sin x}{3+2\cos x}\right]\)。

## 二、填空题（每题3分，共15分）

**11. 已知 \(\lim_{n\to\infty}a_n=2\)，\(\lim_{n\to\infty}b_n=-3\)，则 \(\lim_{n\to\infty}a_n(b_n+1)=\) ______**
**答案：-4**

**12. 已知 \(\lim_{x\to 0}(1+3x)^{a/x}=e\)，则实数 \(a=\) ______**
**答案：\(\frac13\)**

**13. 曲线 \(y=e^{2x-1}+x^2\) 在点 \(\left(\frac12,\frac54\right)\) 处的法线斜率是 ______**
**答案：\(-\frac13\)**
**解析：** \(y'=2e^{2x-1}+2x\)，在 \(x=\frac12\) 处 \(y'=3\)，法线斜率 \(-\frac13\)。

**14. 已知 \(\int_1^2 f(x)dx+2\int_2^3 f(x)dx=2\)，\(2\int_1^2 f(x)dx-\int_2^3 f(x)dx=1\)，则 \(\int_1^3 f(x)dx=\) ______**
**答案：\(\frac75\)**

**15. 已知函数 \(f(x)\) 在 \(\mathbb{R}\) 上有连续导数，\(f(2)=3\)，且 \(\int_0^2 t f(x+t)dt=x^2+1\)，则 \(\int_0^2 f(x)dx=\) ______**
**答案：6**

## 三、计算题（每题6分，共36分）

**16. 求极限 \(\lim_{x\to 1}\left(\frac{1}{x^2-x}-\frac{2}{x^2-1}\right)\)**
**答案：\(-\frac12\)**
**解析：** 通分后得 \(\frac{1-x}{x(x-1)(x+1)}=-\frac{1}{x(x+1)}\)，代入 \(x=1\) 得 \(-\frac12\)。

**17. 求极限 \(\lim_{x\to 0}\frac{\arctan x-x}{\sin x-x}\)**
**答案：2**
**解析：** 泰勒展开，分子 \(-\frac{x^3}{3}\)，分母 \(-\frac{x^3}{6}\)，比值为 2。

**18. 已知函数 \(f(x)=\begin{cases}2a\cos x+b,&x<0\\2,&x=0\\a\sqrt{x+1}-b,&x>0\end{cases}\) 在 \(x=0\) 处连续，求 \(a,b\) 的值。**
**答案：\(a=\frac43,\ b=-\frac23\)**

**19. 求曲线 \(y\ln y-\sin(xy)-x=0\) 在点 \((0,1)\) 处的切线方程。**
**答案：\(y=2x+1\)**

**20. 求不定积分 \(\int(2\tan^2 x-x+5)dx\)**
**答案：\(2\tan x-\frac{x^2}{2}+3x+C\)**

**21. 求定积分 \(\int_0^1 x^2\ln(x^2+1)dx\)**
**答案：\(\frac13\ln2-\frac{\pi}{6}+\frac49\)**

## 四、应用题（每题6分，共12分）

**22. 求曲线 \(xy=1\) 与直线 \(y=-x+2\)，\(y=4x\) 所围成的图形的面积。**
**答案：\(\ln\frac52-\frac{161}{200}\)**
**解析：** 交点 \(\left(\frac25,\frac85\right)\)，\(\left(\frac12,2\right)\)，\((1,1)\)，分段积分可得。

**23. 求函数 \(f(x)=(2x^2-8x)\ln x-3x^2+16x\) 的极值，并判断是极大值还是极小值。**
**答案：极大值 \(f(2)=20-8\ln2\)，极小值 \(f(e)=8e-e^2\)**
**解析：** \(f'(x)=4(x-2)(\ln x-1)\)，驻点 \(x=2,e\)，二阶导判断。

## 五、证明题（7分）

**24. 已知函数 \(f(x)\) 在 \([0,1]\) 上连续，在 \((0,1)\) 内可导，当 \(x\in(0,1)\) 时，都有 \(|f'(x)|\le M\)，且 \(\int_0^1 f(x)dx=0\)，证明：**
（1）存在 \(x_0\in(0,1)\)，使得 \(f(x_0)=0\)；
（2）不等式 \(f^2(0)+f^2(1)\le M^2\)。

**证明：**
（1）由积分中值定理，存在 \(x_0\in(0,1)\) 使 \(f(x_0)=0\)。
（2）由拉格朗日中值定理，存在 \(c_1\in(0,x_0)\)，\(c_2\in(x_0,1)\)，使
\[
|f(0)|\le Mx_0,\quad |f(1)|\le M(1-x_0)
\]
故
\[
f^2(0)+f^2(1)\le M^2[x_0^2+(1-x_0)^2]\le M^2
\]
因为 \(x_0^2+(1-x_0)^2\le1\)。

# 2023年山东省专升本《高等数学III》真题答案与解析

## 一、单项选择题（每题3分，共30分）

**1. 函数 \(y=e^{\sqrt{x-2}}\) 的定义域为（ ）**
**答案：A**
**解析：** \(x-2\ge0\Rightarrow x\ge2\)。

**2. 下列函数在其定义域内有界的是（ ）**
**答案：D**
**解析：** \(\cos x\) 有界。

**3. 当 \(x\to 0\) 时，以下不是与 \(x\) 为等价无穷小量的是（ ）**
**答案：C**
**解析：** \(1-\cos x\sim\frac{x^2}{2}\)。

**4. 已知函数 \(f(x)=\begin{cases}\ln x,&x>1\\x^2,&x\le1\end{cases}\)，则 \(x=1\) 是函数 \(f(x)\) 的（ ）间断点**
**答案：B**
**解析：** 左极限 \(1\)，右极限 \(0\)，为跳跃间断点。

**5. 函数 \(y=\sqrt{2x^2+3}\)，则 \(dy=\)（ ）**
**答案：B**
**解析：** \(dy=\frac{2x}{\sqrt{2x^2+3}}dx\)。

**6. 函数 \(y=\ln(2x+5)\)，则 \(y''=\)（ ）**
**答案：A**
**解析：** \(y''=-\frac{4}{(2x+5)^2}\)。

**7. 已知 \(\sin x\) 是 \(f(x)\) 的原函数，则 \(f(2x)\) 的原函数是（ ）**
**答案：B（按常见题型，应为 \(\frac12\sin2x\)，选项可能漏系数）**
**解析：** \(f(x)=\cos x\)，\(f(2x)=\cos2x\)，原函数为 \(\frac12\sin2x\)。

**8. 函数 \(y=(x-1)e^x\) 的拐点是（ ）**
**答案：B**
**解析：** \(y''=(x+1)e^x\)，\(x=-1\)，拐点 \(\left(-1,-\frac{2}{e}\right)\)。

**9. 已知 \(f(x)\) 在 \([1,4]\) 可导，\(f(4)=1\)，\(\int_1^4 xf'(x)dx=3\)，则 \(\int_1^4 f(x)dx=\)（ ）**
**答案：B（若 \(f(1)=1\)，则 \(\int_1^4 f=0\)）**
**解析：** 分部积分得 \(\int_1^4 f=4f(4)-f(1)-3=1-f(1)\)。

**10. 已知 \(f(x)=\int_0^{2x}x\sin t^2dt\)，则 \(f'(x)=\)（ ）**
**答案：D**
**解析：** \(f(x)=x\int_0^{2x}\sin t^2dt\)，求导得 \(\int_0^{2x}\sin t^2dt+2x\sin4x^2\)。

**答案：\(\frac{15}{2}\)**

**23. 已知实数 \(a\neq0\)，求函数 \(f(x)=a^2x^3-6ax^2+9x\) 的极值，并判断是极大值还是极小值。**
**答案：**
- 当 \(a>0\) 时，\(x=\frac1a\) 为极大值点，极大值 \(\frac4a\)；\(x=\frac3a\) 为极小值点，极小值 \(0\)。

## 五、证明题（6分）

**24. 设函数 \(f(x)\) 在 \([1,4]\) 内具有二阶导数，且 \(3f(2)=2f(1)+f(4)\)，证明在 \((1,4)\) 内存在一点 \(\xi\)，使得 \(f''(\xi)=0\)。**
**证明：** 由拉格朗日中值定理，存在 \(c_1\in(1,2)\)，\(c_2\in(2,4)\)，使
\[
f'(c_1)=f(2)-f(1),\quad f'(c_2)=\frac{f(4)-f(2)}{2}
\]
由条件得 \(f'(c_1)=f'(c_2)\)，再由罗尔定理，存在 \(\xi\in(c_1,c_2)\subset(1,4)\)，使 \(f''(\xi)=0\)。

# 2025年山东省专升本《高等数学III》真题答案与解析

## 一、单项选择题（每题3分，共30分）

**1. 函数 \(y=\frac{1}{\sqrt{9-x^2}}\) 的定义域为（ ）**
**答案：B**
**解析：** \(9-x^2>0\Rightarrow -3<x<3\)。

**2. 下列函数是单调递增函数的是（ ）**
**答案：B**
**解析：** \(e^x\) 单调递增。

**3. 当 \(x\to0\) 时，下列函数为无穷大量的是（ ）**
**答案：C**
**解析：** \(\frac1x\to\infty\)。

**4. 函数 \(y=\frac{3x+2}{x+5}\) 的水平渐近线是（ ）**
**答案：D**
**解析：** \(x\to\infty\) 时，\(y\to3\)。

**5. 已知 \(f(x)\) 在 \(x=2\) 处可导且 \(\lim_{h\to0}\frac{f(2+4h)-f(2+h)}{h}=6\)，则 \(f'(2)=\)（ ）**
**答案：C**
**解析：** 极限 \(=3f'(2)=6\Rightarrow f'(2)=2\)。

**6. 已知函数 \(y=y(x)\) 由方程 \(e^y=\ln x-xy\) 所确定，则 \(dy=\)（ ）**
**答案：A**
**解析：** 隐函数求导得 \(dy=\frac{1-xy}{x(e^y+x)}dx\)。

**7. 已知 \(I_1=\int_0^{\pi/4}\sin x^2dx\)，\(I_2=\int_0^{\pi/4}\sin x^3dx\)，\(I_3=\int_0^{\pi/4}\sin x^4dx\)，则下列不等式成立的是（ ）**
**答案：C**
**解析：** 在 \((0,\pi/4)\) 上，\(x^4<x^3<x^2\)，故 \(I_3<I_2<I_1\)。

**8. 已知 \(f(x)\) 在 \(\mathbb{R}\) 上连续且 \(\int_0^1 xf(x^2)dx=3\)，则 \(\int_0^1 f(x)dx=\)（ ）**
**答案：D**
**解析：** 令 \(t=x^2\)，得 \(\frac12\int_0^1 f(t)dt=3\Rightarrow \int_0^1 f=6\)。

**9. 已知 \(f(x)\) 在 \([0,2]\) 上连续且 \(\int_0^2[f(x)+xf'(x)]dx=1\)，则 \(f(2)=\)（ ）**
**答案：B**
**解析：** \(\int_0^2 xf'(x)dx=2f(2)-\int_0^2 f\)，故原积分 \(=2f(2)=1\Rightarrow f(2)=\frac12\)。

**10. 已知 \(F(x)=\int_0^x\cos(x+t)^2dt\)，则 \(F'(x)=\)（ ）**
**答案：A**

## 五、证明题（7分）

**24. 已知函数 \(f(x)\) 在 \([0,2]\) 上连续，在 \((0,2)\) 上二阶可导且 \(f(0)=1\)，\(f(1)=2\)，\(f(2)=4\)，证明：存在 \(\xi\in(0,2)\)，使得 \(f'(\xi)=1\)。**
**证明：** 在区间 \([0,1]\) 上对 \(f(x)\) 应用拉格朗日中值定理，存在 \(\xi\in(0,1)\subset(0,2)\)，使得
\[
f'(\xi)=\frac{f(1)-f(0)}{1-0}=2-1=1
\]
故存在 \(\xi\in(0,2)\)，使 \(f'(\xi)=1\)。
