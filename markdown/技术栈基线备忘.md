## 二、旧接口清单（后端手册 · 合计 17 个）

### 用户 `/api/user`
| 接口 | 方法 | 路径 | Token |
|---|---|---|---|
| 发送登录验证码 | POST | `/api/user/login/send-code` | 否 |
| 邮箱验证码登录（未注册自动注册） | POST | `/api/user/login` | 否 |
| 刷新 Access Token | POST | `/api/user/token/refresh` | 否 |
| 登出（吊销 Refresh） | POST | `/api/user/logout` | 否 |
| 获取用户信息 | GET | `/api/user/info` | 是（Access JWT） |
| 修改资料（昵称/头像 URL） | PUT | `/api/user/info` | 是（Access JWT） |
| 上传头像（OSS） | POST | `/api/user/avatar` | 是（multipart `file`） |
| 获取备考设置 | GET | `/api/user/exam-preference` | 是（Access JWT） |
| 保存备考设置 | PUT | `/api/user/exam-preference` | 是（Access JWT） |
| 删除备考设置 | DELETE | `/api/user/exam-preference` | 是（Access JWT） |
| 修改资料（昵称/头像） | PUT | `/api/user/info` | 是 |
| 修改密码 | PUT | `/api/user/password` | 暂缓 |
| 发送忘记密码验证码 | POST | `/api/user/forgot-password/send` | 暂缓 |
| 重置密码 | POST | `/api/user/forgot-password/reset` | 暂缓 |

**账号约定（一期）**
- **邮箱验证码登录**：`email` + 6 位验证码；**无密码登录**；未注册邮箱验证通过后**自动注册**
- **双 Token 登录态**：Access JWT **30 分钟**（`ul.jwt.access-ttl-ms`）+ Refresh 存 Redis **7 天**（`ul.jwt.refresh-ttl-seconds`）；业务 API 只带 Access；过期用 Refresh 换新
- **昵称**：自动注册时服务端默认「升本er + 随机串」；可 `PUT /api/user/info` 修改
- **头像**：自动注册时写入默认 `avatar_url`；可随后修改；**图片文件存阿里云 OSS**（见 §四 OSS）
- 不用用户名、**不收集手机号**（不做短信）

### 院校（公开）
| 接口 | 方法 | 路径 |
|---|---|---|
| 院校分页查询 | GET | `/api/school/list`（kw / 筛选可选；专业用 `majorDictId` 精确） |

| 院校开设专业列表 | GET | `/api/school/{id}/majors` |

| 备考考试科目选项 | GET | `/api/exam-subjects/options?province=广东&majorCategory=计算机类` |

> 表结构：`major_dict`（专业词典）+ `school_major`（院校开设）+ `exam_subject`（考试科目字典）+ `exam_subject_rule`（省份/专业规则）；已废弃单表 `major`。
