每个模块都有三个配置文件,分别是application和dev和local
其中主文件读取的是dev的配置,为的是到到时候服务部署到docker的时候不用修改配置文件直接根据容器名读取配置
local文件是本地测试的时候手动让spring强制读取local配置替换dev占位

## 阿里云 OSS（图片存储）

用户头像等图片走 **阿里云 OSS**，Bucket **`up-learn`**（华北2 北京 `oss-cn-beijing`）。  
AccessKey / Secret 仅写在各服务 `application-local.yml`（或环境变量），**勿提交 Git**。建议字段：

```yaml
ul:
  oss:
    endpoint: oss-cn-beijing.aliyuncs.com
    bucket: up-learn
    enabled: true
    # access-key-id / access-key-secret 本机填写（展示头像也需要密钥生成签名 URL）
```

Bucket 读写权限为 **私有**；库内存 canonical URL，接口返回 **presigned URL**（默认 2h）。本地若未填 AccessKey，已上传的 OSS 头像将无法显示（签名依赖密钥；上传另需 `enabled: true`）。

IDE 中 `ul.oss` 未知属性警告：由 `user-service` 的 `META-INF/additional-spring-configuration-metadata.json` 登记；刷新 Maven / Rebuild 后消失。
