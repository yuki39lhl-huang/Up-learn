## 二、旧接口清单（后端手册 · 合计 17 个）

### 用户 `/api/user`
| 接口 | 方法 | 路径 | Token |
|---|---|---|---|
| 注册 | POST | `/api/user/register` | 否 |
| 登录 | POST | `/api/user/login` | 否 |
| 获取用户信息 | GET | `/api/user/info` | 是 |
| 修改资料（昵称/头像） | PUT | `/api/user/info` | 是 |
| 修改密码 | PUT | `/api/user/password` | 是 |
| 发送忘记密码验证码 | POST | `/api/user/forgot-password/send` | 否 |
| 重置密码 | POST | `/api/user/forgot-password/reset` | 否 |

**账号约定（一期）**
- **邮箱登录**：注册/登录 body 以 `email` + `password` 为主；不用用户名、**不收集手机号**（不做短信服务）
- **昵称**：注册时服务端默认生成（约定前缀 + 随机串）；用户注册完成后可 `PUT /api/user/info` 修改
- **头像**：注册时写入默认 `avatar_url`；用户可随后修改
- **忘记密码**：验证码走**邮箱**（非短信）

### 院校（公开）
| 接口 | 方法 | 路径 |
|---|---|---|
| 院校分页列表 | GET | `/api/school/list` |
| 院校详情 | GET | `/api/school/{id}` |
| 搜索院校 | GET | `/api/school/search?kw=xxx` |
| 院校的专业列表 | GET | `/api/school/{id}/majors` |
| 专业详情 | GET | `/api/major/{id}` |

### 刷题（需 Token）

说明：下列「设计对齐补充」已按 Stitch「专升本招生查询与刷题平台 Web 设计」补齐路径归属；**官网落地页无后端接口**，不列入（UI 定稿见 §5.6）。

### 2.1 设计对齐 · 扩展既有（school-service）

- `GET /api/school/list`、`GET /api/school/search` 增加可选查询：`province`、`type`（公办/民办）、`year`、`majorCategory`、`preferPublic`（保留原 `kw`）
- 列表/详情 VO 补充：`city`、`typeTag`、`majorCount`、`minScore`、`enrollment`、`tuition`
- `GET /api/school/{id}/majors`、`GET /api/major/{id}` 补充：考试科目、均分、招生人数、学费

### 2.2 设计对齐 · 新增（user-service · 目标院校）
