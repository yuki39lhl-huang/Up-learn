# 2024年广东省专升本《生理学》真题答案与解析

## 一、单项选择题（每题2分，共50分）

**1. 能引起机体发生反应的各种内外环境变化称为（ ）**
**答案：C（刺激）**
**解析：** 刺激是能引起机体发生反应的内外环境变化。反射是反应方式，兴奋是反应，应激是应激反应。

**2. 取蛙坐骨神经标本研究神经干动作电位的传导，其实验方法是（ ）**
**答案：D（急性离体实验）**
**解析：** 蛙坐骨神经标本是离体组织，属于急性离体实验。

**3. 骨骼肌静息电位对什么离子的通透性最高（ ）**
**答案：C（K+）**
**解析：** 静息时膜主要对K+有通透性，K+外流形成静息电位。

**4. 75%的乙醇擦拭后，乙醇通过哪种方式进入体内（ ）**
**答案：A（单纯扩散）**
**解析：** 乙醇脂溶性小分子，顺浓度梯度，不耗能，属于单纯扩散。

**5. 外源性凝血的启动因子（ ）**
**答案：D（组织因子）**
**解析：** 外源性凝血由组织因子（凝血因子III）启动。

**6. 合成血红蛋白的原料是（ ）**
**答案：B（铁和蛋白质）**
**解析：** 血红蛋白由珠蛋白和血红素组成，血红素需要铁。

**7. 影响主要收缩压的是（ ）**
**答案：B（每搏输出量）**
**解析：** 每搏输出量增加，收缩压明显升高，舒张压升高不多。

**8. 窦房结细胞具有自律性的原因是（ ）**
**答案：C（4期自动去极化期）**
**解析：** 窦房结细胞4期自动去极化达到阈电位产生动作电位。

**9. 下列因素与动作电位在神经纤维传导无关的是（ ）**
**答案：D（刺激强度）**
**解析：** 动作电位传导与刺激强度无关，只要达到阈值，动作电位幅度不变（全或无）。温度、髓鞘、直径影响传导速度。

**10. 以下对心指数描述正确的是（ ）**
**答案：D（每搏输出量×心率÷体表面积）**
**解析：** 心指数=心输出量/体表面积，心输出量=每搏输出量×心率。

**11. 以下描述错误的是（ ）**
**答案：A（呼吸膜5层）**
**解析：** 呼吸膜有6层：含肺表面活性物质的液体层、肺泡上皮细胞层、上皮基底膜、肺泡上皮和毛细血管基膜之间的间隙、毛细血管基膜、毛细血管内皮细胞层。B、C、D描述正确。

**12. 一氧化碳中毒的原因（ ）**
**答案：C（血红蛋白释放氧气减少）**
**解析：** CO与Hb亲和力高，形成HbCO，使Hb失去携氧能力，且氧解离曲线左移，释放O2减少。

**13. 下列哪项是最大促进促胰液素分泌（ ）**
**答案：A（盐酸）**
**解析：** 促胰液素由小肠黏膜S细胞分泌，盐酸是最强刺激物。

**14. 胆汁中的哪个成分能够促进脂肪分解（ ）**
**答案：A（胆盐）**
**解析：** 胆盐乳化脂肪，促进脂肪消化吸收。

**15. 不能滤过的半透膜的是（ ）**
**答案：血细胞和血浆蛋白**
**解析：** 肾小球滤过膜不能滤过血细胞和大分子血浆蛋白。题目不完整，仅能给出常见答案。

**16. 大量饮清水导致抗利尿激素减少原因（ ）**
**答案：D（血浆晶体渗透压降低）**
**解析：** 大量饮清水后，血浆晶体渗透压降低，抑制ADH释放，尿量增加（水利尿）。

**17. 肾脏合成并释放的是（ ）**
**答案：C（促红细胞生成素）**
**解析：** 肾脏合成并释放EPO，促进红细胞生成。ADH由下丘脑合成，神经垂体释放。

**18. 颜色视野范围最大的是（ ）**
**答案：A（白色）**
**解析：** 视野范围：白色>黄>蓝>红>绿。

**19. 不属于非突触传递的特点（ ）**
**答案：A（双向传递）**
**解析：** 非突触传递（容积传递）特点：无特定突触结构，作用弥散，无特定接头后膜，传递单向。双向传递是电突触的特点。

**20. 心肌缺血疼痛部位是（ ）**
**答案：A（左肩、左上臂）**
**解析：** 心绞痛牵涉痛常放射至左肩、左臂内侧。

**21. 去甲肾上腺素与糖皮质激素对机体的作用属于（ ）**
**答案：C（允许作用）**
**解析：** 糖皮质激素对去甲肾上腺素有允许作用，使血管对去甲肾上腺素反应性增强。

**22. 成年人调节血钙最重要的激素（ ）**
**答案：D（甲状旁腺激素）**
**解析：** PTH是调节血钙最重要的激素，升高血钙。

**23. 哺乳期乳腺泌乳的维持（ ）**
**答案：B（缩宫素和催乳素的作用）**
**解析：** 催乳素促进泌乳，缩宫素引起射乳，维持泌乳需要两者。

**24. 精子在女性生殖道内待留一段时间才能获得使卵子受精的能力（ ）**
**答案：A（精子获能）**
**解析：** 精子在女性生殖道内获得受精能力的过程称精子获能。

**25. 同一强度的触觉连续刺激后反应突然下降，属于（ ）**
**答案：A（适应）**
**解析：** 感受器对恒定刺激的反应逐渐减弱称适应。

## 二、名词解释（每题3分，共15分）

**26. 血型**
**答案：** 血型是指血细胞膜上特异性抗原的类型，通常指红细胞血型。

**27. 应急反应**
**答案：** 应急反应是指机体在紧急情况下，交感-肾上腺髓质系统活动增强，引起心率加快、血压升高、血糖升高等一系列反应。

**28. 妊娠**
**答案：** 妊娠是指子代在母体子宫内生长发育的过程，从受精卵着床到胎儿娩出。

**29. 肾小球滤过率**
**答案：** 单位时间内（每分钟）两肾生成的超滤液量，正常约125ml/min。

**30. 胃排空**
**答案：** 食物由胃排入十二指肠的过程。

## 三、简答题（每题5分，共15分）

**31. 简述影响骨骼肌收缩效能的因素。**
**答案：** 前负荷、后负荷、肌肉收缩能力、收缩总和（频率、串连等）。前负荷影响初长度，后负荷影响收缩速度，收缩能力改变效能。

**32. 简述肺泡表面活性物质的主要作用及生理意义。**
**答案：** 主要作用：降低肺泡表面张力，维持肺泡稳定性，防止肺泡萎陷，减少肺间质和肺泡水肿，降低吸气阻力。生理意义：维持大小肺泡稳定性，防止肺不张，减少吸气做功。

**33. 根据表格，说明安静状态、运动状态下机体最主要的产热器官分别是？并说明在环境温度20~25℃时机体的主要产热方式。**
**答案：** 安静状态最主要产热器官：内脏（尤其肝脏）；运动状态：肌肉。环境温度20~25℃时主要产热方式：安静时以内脏代谢产热为主，寒冷时骨骼肌战栗产热和非战栗产热。20-25℃属于适宜温度，主要靠内脏和脑的代谢产热。

## 四、论述题（10分）

**34. 论述心动周期中左心室收缩期压力、瓣膜、容积和血流方向的变化。**
**答案：** 左心室收缩期包括等容收缩期、快速射血期、减慢射血期。
（1）等容收缩期：心室收缩，房室瓣关闭，半月瓣未开，心室容积不变，压力急剧升高，血流无进出。
（2）快速射血期：室内压超过主动脉压，半月瓣开放，血液快速射入主动脉，心室容积迅速减小。
（3）减慢射血期：室内压略低于主动脉压，但血液靠惯性继续射入，容积继续减小，流速减慢。
压力：等容收缩期压力升最快，快速射血期达峰值，减慢射血期下降。瓣膜：房室瓣关闭，半月瓣开放。容积：减小。血流方向：心室→主动脉。

## 五、案例分析题（10分）

**35. 帕金森病。**
（1）该患者的主要病变部位在哪？
**答案：** 黑质致密部多巴胺能神经元变性坏死。

（2）结合症状，分析该病机制。
**答案：** 黑质多巴胺能神经元减少，多巴胺合成不足，导致纹状体多巴胺与乙酰胆碱平衡失调，胆碱能相对亢进，出现静止性震颤、肌张力增高、运动迟缓。

（3）采用左旋多巴类药物治疗该病的依据？
**答案：** 左旋多巴是多巴胺前体，能通过血脑屏障，在脑内转化为多巴胺，补充纹状体多巴胺不足，恢复平衡，缓解症状。

## 二、名词解释（每题3分，共15分）

**26. 稳态**
**答案：** 内环境理化性质保持相对稳定的状态。

**27. 去极化**
**答案：** 静息电位减小，膜内负电位减小或消失，甚至反转为正的过程。

**28. 肺通气**
**答案：** 肺与外界环境之间的气体交换过程。

**29. 感受器**
**答案：** 分布于体表或组织内部，能感受机体内外环境变化的结构或装置。

**30. 激素**
**答案：** 由内分泌腺或内分泌细胞分泌的高效能生物活性物质，经体液传递，调节机体功能。

## 三、简答题（每题5分，共15分）

**31. 简述小肠能成为主要吸收部位的原因。**
**答案：** 小肠面积大（皱襞、绒毛、微绒毛），食物停留时间长，消化液丰富，吸收途径多，小肠绒毛血流和淋巴丰富。

**32. 腱反射的反射弧组成。**
**答案：** 感受器（肌梭）、传入神经、中枢（脊髓前角）、传出神经、效应器（同一肌肉的肌纤维）。单突触反射。

**33. 简述输血的原则。**
**答案：** 同型输血，交叉配血试验，首选同型，紧急可异型但需主侧不凝集，输血前必须做交叉配血。

## 四、论述题（10分）

**34. 给家兔（2.5kg）注射20%葡萄糖溶液10ml，家兔的尿量如何变化，机制是什么？**
**答案：** 尿量增加，出现糖尿。机制：静脉注射高渗葡萄糖，血糖浓度迅速升高，超过肾糖阈（约180mg/dl），肾小管不能全部重吸收葡萄糖，小管液渗透压升高，水重吸收减少，尿量增加（渗透性利尿）。

## 五、案例分析题（10分）

**35. 高血压性心脏病，左心功能不全。**
（1）心率加快时血压有何变化？
**答案：** 心率加快，心输出量增加，收缩压升高，舒张压可能因舒张期缩短而升高或不变，但若过快，心输出量下降，血压降低。

（2）除心率外，影响动脉血压因素还有哪些？
**答案：** 每搏输出量、外周阻力、大动脉弹性、循环血量与血管容量匹配。

（3）该患者为什么会出现呼吸困难？
**答案：** 左心功能不全导致肺淤血、肺水肿，肺顺应性降低，气道阻力增加，肺换气障碍，引起呼吸困难。

# 2022年广东省专升本《生理学》真题答案与解析

## 一、单项选择题（每题2分，共50分）

**1. 体液调节的特点（ ）**
**答案：C（持久）**
**解析：** 体液调节缓慢、持久、广泛。

**2. 神经纤维动作电位上升支的离子流动是（ ）**
**答案：D（Na+内流）**

**3. 下列情况会引起血细胞比容降低的是（ ）**
**答案：A（缺铁性贫血）**
**解析：** 红细胞减少，血细胞比容降低。其他导致血液浓缩，比容升高。

**4. 心率超过180/min，导致血输出量下降的主要原因是（ ）**
**答案：B（心室舒张期变短）**
**解析：** 心率过快，舒张期缩短，充盈不足，每搏输出量减少。

**5. 可用于诊断早期妊娠的激素是（ ）**
**答案：A（hCG）**

**6. 心脏不会发生强直性收缩的原因是（ ）**
**答案：B（有效不应期长）**
**解析：** 心肌有效不应期特别长，相当于整个收缩期和舒张早期，不会发生强直收缩。

**7. 下列能促进血液凝固的方法是（ ）**
**答案：D（提供粗糙面）**
**解析：** 粗糙面可激活凝血因子XII，促进凝血。

**8. 按压颈动脉压力感受器使其增强可导致（ ）**
**答案：B（心率减慢，血压降低）**

**9. 氧气在血液中的主要运输方式是（ ）**
**答案：B（氧合血红蛋白）**

**10. 下列物质中属于第二信使的是（ ）**
**答案：C（cAMP）**

**11. 中枢化学感受器敏感的刺激物是（ ）**
**答案：D（脑脊髓中的H+）**
**解析：** 中枢化学感受器对脑脊液H+敏感，CO2通过血脑屏障形成H+。

**12. 胸膜腔内压示意图，平静呼吸时正常人胸膜腔变化的曲线为（ ）**
**答案：** 胸膜腔内压始终为负压，吸气时更负，呼气时负值减小。需根据图片选择对应曲线。

**13. 食物胃排空速度快慢顺序，正确的是（ ）**
**答案：C（糖>蛋白质>脂肪）**

**14. 下列与肾小球有效滤过压形成无关的是（ ）**
**答案：B（血浆晶体渗透压）**

## 三、简答题（每题5分，共15分）

**31. 人从长期蹲着突然站起，暂时感到头晕。从静脉回心血量的影响因素来解释这种情况。**
**答案：** 久蹲时下肢静脉受压，血液回流受阻，突然站起，下肢血管扩张，血液淤积下肢，静脉回心血量减少，心输出量减少，血压下降，脑供血不足，头晕。

**32. 小脑损害的人，走路不稳，试结合案例简述小脑的生理功能。**
**答案：** 小脑功能：维持身体平衡（前庭小脑）、调节肌紧张（脊髓小脑）、协调随意运动（皮层小脑）。损害后出现平衡障碍、共济失调、意向性震颤。

**33. 结合肺通气量和肺泡通气量的计算方式及其数值，并以肺通气为依据，判断两种呼吸形式哪个更有效。**
**计算：**
浅快：肺通气量=250×24=6000ml/min，肺泡通气量=(250-150)×24=100×24=2400ml/min。
深慢：肺通气量=1000×6=6000ml/min，肺泡通气量=(1000-150)×6=850×6=5100ml/min。
**答案：** 深慢呼吸肺泡通气量更大，更有效。

## 四、论述题（10分）

**34. 试述易化扩散和单纯扩散的异同点，并举例说明。**
**答案：**
相同点：都是顺浓度梯度或电化学梯度转运，不耗能，属于被动转运。
不同点：单纯扩散：脂溶性小分子，直接通过脂质双分子层，无需载体，如O2、CO2、乙醇。易化扩散：非脂溶性或脂溶性小的物质，需膜蛋白帮助，包括载体介导（葡萄糖进入红细胞）和通道介导（离子通道）。易化扩散有特异性、饱和性。

## 五、案例分析题（10分）

**35. 甲状腺功能亢进。**

**答案：** 基础代谢率增高。

（2）甲状腺的主要生理功能。
**答案：** 促进生长发育，促进新陈代谢，提高神经系统兴奋性，影响心血管等。

（3）病人的T3和T4升高，导致TSH降低，这是一种什么调节机制？
**答案：** 负反馈调节。

## 四、论述题（10分）

**34. 运动时血压突然升高，压力感受性反射会引起血压如何改变？请阐述其过程。**
**答案：** 运动时血压升高，刺激颈动脉窦和主动脉弓压力感受器，传入冲动增加，到达延髓心血管中枢，使心迷走中枢兴奋，心交感中枢和缩血管中枢抑制，传出冲动改变，导致心率减慢、心收缩力减弱、血管舒张，外周阻力降低，血压回降。这是负反馈调节，缓冲血压升高。

## 五、案例分析题（10分）

**35. 肾病综合征，服用糖皮质激素。**
（1）向心性肥胖的出现是药物副作用还是肾病综合征的表现？
**答案：** 药物副作用（糖皮质激素副作用）。

（2）试述糖皮质激素的主要生理作用。
**答案：** 调节物质代谢（升高血糖、促进蛋白质分解、脂肪重新分布）、抗炎、抗过敏、抗休克、免疫抑制、允许作用、对血细胞影响等。

（3）请问糖皮质激素类药物可以突然停药吗？请回答其原因。
**答案：** 不可以。长期使用糖皮质激素，反馈抑制下丘脑-腺垂体-肾上腺皮质轴，突然停药会导致肾上腺皮质功能不全，甚至危象。需逐渐减量。
