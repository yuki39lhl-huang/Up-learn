# 2024年广东省专升本《大学语文》真题答案与解析

## 一、单项选择题（每题1分，共12分）

**1. 下列关于《诗经》的表述，不正确的是（ ）**
**答案：D**
**解析：** 汉代传《诗》有齐、鲁、韩、毛四家，魏晋以后，齐、鲁、韩三家逐渐亡佚，唯《毛诗》得以通行。D项“唯韩诗得以通行”错误。

**2. 通过纪行叙事寄托故国之思，表达遭遇放逐的痛楚与激愤的作品是（ ）**
**答案：A（《哀郢》）**
**解析：** 《哀郢》是屈原《九章》之一，写楚国郢都被秦攻陷后，诗人流亡途中对故国的思念与悲痛。

**3. 欧阳修在《五代史伶官传序》中，认为国家政权兴盛与衰败主要取决于（ ）**
**答案：B（人事）**
**解析：** 原文“盛衰之理，虽曰天命，岂非人事哉”，强调人事决定国家兴衰。

**4. 郑燮在《范县署中寄舍弟墨第四书》中，称天地间第一等人是（ ）**
**答案：B（农）**
**解析：** 郑燮认为“天地间第一等人只有农夫”，肯定农民的地位。

**5. 下列选项中，属于“移于景”写法的诗句是（ ）**
**答案：C（行宫见月伤心色，夜雨闻铃肠断声）**
**解析：** 将“伤心”“肠断”的情感移入“月”“铃”之景，属于移情于景。

**6. 睢景臣《般涉调·哨遍》（高祖还乡）的叙事视角是（ ）**
**答案：B（百姓）**
**解析：** 作品以乡民视角讽刺刘邦还乡，具有民间叙事色彩。

**7. 余秋雨《都江堰》一文中，用来跟都江堰相比的另一古代工程是（ ）**
**答案：A（长城）**
**解析：** 文章将都江堰与长城对比，突出都江堰的造福民生。

**8. 陈启佑《永远的蝴蝶》一文中，怀念的人是（ ）**
**答案：D（未婚妻）**
**解析：** 小说写“我”的未婚妻樱子因车祸去世。

**9. 鲁迅《论睁了眼看》批判的思想和文艺是（ ）**
**答案：A（瞒和骗）**
**解析：** 鲁迅批判不敢正视现实的“瞒和骗”的文艺。

**10. 朱光潜《慢慢走，欣赏啊！——人生的艺术化》没有出现的典故是（ ）**
**答案：C（江郎才尽）**
**解析：** 文中出现东施效颦、孟敏堕甑、王徽之访戴等典故，未出现“江郎才尽”。

**11. 马丁·路德·金《我有一个梦想》演讲词中的“梦想”是（ ）**
**答案：A（平等自由）**
**解析：** 演讲核心是争取黑人的平等与自由。

**12. 下列选项中，以明暗两条线索结构篇章讲述三位贫穷艺术家相濡以沫的故事，歌颂普通人心灵之美的作品是（ ）**
**答案：D（《最后的常春藤叶》）**
**解析：** 欧·亨利小说写琼珊、苏艾、贝尔曼三位画家，贝尔曼画最后一片叶子，歌颂普通人心灵之美。

## 二、翻译加点的字（每题1分，共5分）

**13. 保民而王，莫之能御也。**
**答案：** 保：安定，安抚；王：称王，统一天下；御：抵御，阻挡。

**14. 威后问使者曰：“岁亦无恙耶？”**
**答案：** 岁：年成，收成；恙：忧患，灾害。

**15. 河海不择细流，故能就其深。**
**答案：** 择：选择，引申为拒绝、排斥；就：成就，达到。

**16. 秦人开关延敌，九国之师逡巡而不敢进。**
**答案：** 延：延纳，迎接；逡巡：迟疑徘徊。

**17. 将崇极天之峻，永保无疆之休。**
**答案：** 崇：推崇，崇尚；休：美善，福禄。

## 三、句子翻译题（每题2分，共8分）

**18. 百姓皆以王为爱也，臣固知王之不忍也。**
**答案：** 百姓都认为大王是吝啬，我本来就知道大王是不忍心。

**19. 是其为人也，上不臣于王，下不治其家，中不索交诸侯。**
**答案：** 这个人的为人，上不向君王称臣，下不治理自己的家业，中不谋求与诸侯交往。

**20. 今足下还归，扬名于匈奴，功显于汉室。**
**答案：** 如今您回归汉朝，在匈奴扬名，在汉室彰显功勋。

**21. 居高以临下，不至于争，为其不足与我角也。**
**答案：** 处在高处面对低处，不至于争执，因为它不足以与我较量。

## 六、阅读题

### 31. 阅读《成都的春天》，回答问题。（10分）

**（1）作者说：“从外面来的朋友，没有一个人不骂成都的天气，但没有一个不爱成都的花木。”这是为什么？请简要概括。（3分）**
**答案：** 成都天气水分多、阴晴不定，冷热不宜，令人气色不好；但成都花木繁多、品质好、价格低廉，四季花开，宜于养花木，所以骂天气而爱花木。

**（2）文章善于运用对比手法，请结合第③段分析其表达效果。（3分）**
**答案：** 将成都春天与北平江南对比，说早一两个月；将成都梅花与无锡梅园、苏州邓尉的粉梅对比，突出成都梅花品种多、颜色丰富、品质高，表达喜爱赞美。

**（3）从作者看来，得过且过的“懒人”是怎样的人，结合文章分析。（4分）**
**答案：** 指在成都悠闲生活熏染下，人变得放松、闲适、安逸，不思紧张竞争，安于享受生活，慢慢消磨斗志，变得懒散、得过且过。茶馆、花会、钓鱼等悠闲生活让人舒适，也让人懒。

### 32. 阅读文言文《新书·先醒》，回答问题。（8分）

**（1）文中两次提到“虢君喜”，请说明原因。（2分）**
**答案：** 第一次：逃亡途中御者早已储备酒食，他高兴有人照顾；第二次：御者说他亡国是因为太贤明，天下君王不贤嫉妒他，他信以为真，高兴。

**（2）御逃亡途中的言行发生了怎样的变化？（3分）**
**答案：** 起初进酒食、如实回答、劝谏；被怒后谢罪；后阿谀奉承说“以大贤也”；趁君枕膝用土块替换逃走。从忠诚到自保、欺骗、背叛。

**（3）这篇文章告诉我们什么道理？（3分）**
**答案：** 不能听信谄媚，要正视自身过失，否则亡国；领导者应虚心纳谏，明辨忠奸。

### 33. 阅读古诗《新柳》《清平乐》，回答问题。（8分）

**（1）两首古诗词都用了拟人手法，请分析说明。（4分）**
**答案：** 《新柳》“拂银塘”将柳拟人；《清平乐》“欺烟困雨”“愁千缕”“羞舞女”将柳拟人，赋予人的情态。

**（2）如何理解《清平乐》中“风流全在轻黄”？（4分）**
**答案：** 早春柳色浅黄，轻盈柔美，最能体现春柳风流神韵，而非深青。表达对早春新柳的喜爱。

## 七、作文题（40分）

**34. 关于“短、快、碎”文化现象。**
**写作思路：**
- 可辩证看待：短快碎文化适应快节奏生活，便于获取信息，但易导致浅阅读、思维碎片化。
- 应坚持深度阅读与系统学习，不能完全被短视频、速成宝典替代。
- 可结合“慢下来”“经典阅读”“独立思考”等角度。

**参考范文提纲：**
1. 开头：指出“短快碎”流行现象。
2. 分析原因：生活节奏快、信息爆炸、技术推动。
3. 辩证影响：利——便捷、高效；弊——浅薄、浮躁、缺乏体系。
4. 提出对策：以深阅读为根基，以碎片化为辅助；培养独立思考。
5. 结尾：在快时代守住慢功夫，在碎片中重建整体。

## 二、古文翻译与断句题（共16分）

### （一）解释加点字（每题1分，共5分）

**13. 保民而王，莫之能御也。**
**答案：** 王：称王；御：抵挡。

**14. 人之道则不然，损不足以奉有余。**
**答案：** 损：减少；奉：供奉，献给。

**15. 乃幽武置大窖中，绝不饮食。**
**答案：** 幽：囚禁；绝：断绝。

**16. 臣闻求木之长者，必固其根本。**
**答案：** 固：使……稳固；根本：根。

**17. 浩浩乎如冯虚御风，而不知其所止。**
**答案：** 冯：通“凭”，乘；御：驾。

### （二）句子翻译（每题2分，共8分）

**18. 忧劳可以兴国，逸豫可以亡身，自然之理也。**
**答案：** 忧虑操劳可以使国家兴盛，安逸享乐可以使自身灭亡，这是自然的道理。

**19. 今不问王而先问岁与民，岂先贱而后尊贵者乎？**
**答案：** 现在不先问君王却先问年成和百姓，难道是把卑贱的放在前、尊贵的放在后吗？

**20. 此数宝者，秦不生一焉，而陛下说之，何也？**
**答案：** 这几件珍宝，秦国一件都不出产，但陛下喜欢它们，为什么呢？

**21. 天下有公利而莫或兴之，有公害而莫或除之。**
**答案：** 天下有公共的利益却没有人去兴办，有公共的祸害却没有人去消除。

## 四、阅读题

### 31. 阅读《雕窝的月亮》，回答问题。（10分）

**（1）文章主要想写赏月，作者为什么还要花费笔墨写给小院挂“雕憩园”横匾的事情？请结合原文分析。（4分）**
**答案：** 交代小院命名由来，表达对“雕窝”地名文化意蕴的认同和正名，为赏月营造雅致环境，体现作者情趣。

**（2）文章多处引用古诗文，有什么作用？（3分）**
**答案：** 增添文化底蕴和诗意，引发思古幽情，衬托月色之美，深化人生感悟。

**（3）请结合文章⑧⑨⑩段的内容，分析作者赏月时的情感变化。（3分）**
**答案：** 初见月出惊喜赞叹；月升中天感到静谧、旷远、惆怅；月上天顶领略孤光冰雪，珍惜相遇，超脱宁静。

### 32. 阅读文言文《吕氏春秋·贵直论》，回答问题。（8分）

**（1）行人烛过认为“鼓之而士不起”的原因是什么？他是如何开展陈述的？请结合原文回答。（5分）**
**答案：** 不是士兵弊病，而是君主不能与士兵同甘共苦。他先直言“亦有君不能耳”，再以献公、惠公、文公三代君主用同样士兵不同结果对比，说明君主态度决定士气。

**（2）请结合全文分析赵简子的形象。（3分）**
**答案：** 起初远立屏蔽后，见士兵不冲锋而叹；被直言后愤怒威胁；听劝后改正，去屏蔽立于矢石所及，一鼓而士乘之；能纳谏、知错能改、勇于实践。

### 33. 阅读杜甫《秋兴八首》，回答问题。（8分）

**（1）《秋兴八首》（其一）如何围绕“秋”字来点题？（4分）**
**答案：** 玉露、枫林、巫山巫峡气萧森、波浪、风云、丛菊、寒衣、暮砧等秋景，渲染萧瑟阴沉，点明秋日。

**（2）这两首诗出自同题组诗，但抒发的情感各有侧重，请结合诗句分析。（4分）**
**答案：** 其一写秋景萧森，抒发羁旅思乡、故园之心；其四写长安如棋、世事变迁，抒发忧国伤时、盛衰之感。

## 五、作文（40分）

**34. 终身学习。**
**写作思路：**
- 知识更新加速，终身学习是个人发展和社会进步的必然要求。
- 可写：学习不应止于学校，应贯穿一生；要主动学习、持续学习。
- 正反对比：疏于学习者被时代淘汰，持续学习者成为弄潮儿。
- 结尾：把学习当作生活方式，方能与时俱进。

# 2022年广东省专升本《大学语文》真题答案与解析

## 一、选择题（每题1分，共15分）

**1. 《赵威后问齐使》中赵威后批评的人物是（ ）**
**答案：A（於陵子仲）**

**2. 下列作品作家体裁关系不正确的是（ ）**
**答案：D（《五代史伶官传序》——欧阳修——传奇）**
**解析：** 应为史论/序，不是传奇。

## 二、古文翻译与断句题（共16分）

### （一）解释加点字（每题1分，共5分）

**16. 是助王息其民者也，何以至今不业也？**
**答案：** 息：繁衍，养育；业：成就功业，使……有职业。

**17. 方其系燕父子以组，函梁君臣之首，入于太庙。**
**答案：** 组：绳索；函：用匣子装。

**18. 既至匈奴，置币遗单于。**
**答案：** 币：礼物；遗：赠送。

**19. 居高以临下，不至于争，为其不足与我角也。**
**答案：** 角：较量。

**20. 去故乡而就远兮，遵江夏以流亡。**
**答案：** 去：离开；遵：沿着。

### （二）句子翻译（每题2分，共8分）

**21. 是以圣人为而不恃，功成而不处，其不欲见贤。**
**答案：** 因此圣人有所作为却不自恃，功成却不自居，他不想显露自己的贤能。

**22. 向使四君却客而不内，疏士而不用，是使国无富利之实而秦无强大之名也。**
**答案：** 假使四位君主拒绝客卿而不接纳，疏远贤士而不任用，这就会使国家没有富足的实际，秦国没有强大的名声。

**23. 老者衣帛食肉，黎民不饥不寒，然而不王者，未之有也。**
**答案：** 老年人穿丝织品吃肉，百姓不挨饿受冻，这样还不能称王天下的，从未有过。

**24. 及其衰也，数十伶人困之，而身死国灭，为天下笑。**
**答案：** 等到他衰败时，几十个伶人围困他，以致自己丧命国家灭亡，被天下人耻笑。

### （三）断句（3分）

**25. 郑人有一子将宦谓其家日必筑坏墙是不善人将窃其巷人亦云不时筑而人果窃之以其子为智以巷人告者为盗**
**答案：** 郑人有一子将宦 / 谓其家曰 / 必筑坏墙 / 是不善人将窃 / 其巷人亦云 / 不时筑 / 而人果窃之 / 以其子为智 / 以巷人告者为盗。

## 四、阅读题

### 34. 阅读《桃花鼓声安塞》，回答问题。（10分）

**（1）文中反复提到真武洞，有什么作用？（3分）**
**答案：** 真武洞是线索，神秘浪漫，连接少年想象与安塞文化，象征安塞古老浪漫、生命力，增强文化底蕴。

**（2）在第9段中，提到了杜甫、田启元、彭德怀，有什么用意？（3分）**
**答案：** 说明安塞历史悠久、英雄辈出、有革命传统，腰鼓艺术有深厚历史底蕴和阳刚之气。

**（3）文章用“桃花鼓声安塞”为题，有什么妙处？结合全文分析。（4分）**
**答案：** 桃花与鼓声结合，柔美与刚劲，表现安塞春天与腰鼓艺术，象征生命热情，点明主旨，富有诗意。

### 35. 阅读《田饶事鲁哀公》，回答问题。（7分）

**（1）田饶所说鸡与鸿鹄各喻指了什么样的人？（3分）**
**答案：** 鸡喻指身边贤士/近处人才，有文武功勇仁信五德却不被重视；鸿鹄喻指远方之人/外来人才，无五德却因远来被尊崇。

**（2）文中所引的《诗》中的“乐土”在这里指什么？（4分）**
**答案：** 指能重用贤才、实现理想的地方，田饶去燕并受重用，燕国政治太平。

### 36. 阅读《官舍竹》，回答问题。（6分）

**（1）请赏析颈联“声拂琴床生雅趣，影侵棋局助清欢”。（3分）**
**答案：** 从听觉写竹声拂琴床生雅趣，视觉写竹影映棋局助清欢，视听结合，拟人，表现竹的高雅和诗人闲适清欢。

**（2）请结合全诗，谈谈你对尾联的理解。（3分）**
**答案：** 明年即使调任离开，今冬还能在雪里看竹。表达对竹的喜爱、坚守孤贞，随遇而安。

## 二、古文翻译与断句题

### （二）句子翻译（每题2分，共8分）

**18. 律知武终不可胁，白单于。单于愈益欲降之。**
**答案：** 卫律知道苏武终究不可胁迫，禀告单于。单于更加想要使他投降。

**19. 夫祸患常积于忽微，智勇多困于所溺，岂独伶也哉。**
**答案：** 祸患常常从微小的事积累，聪明勇敢的人多被自己溺爱的事物困扰，难道只是伶人吗？

**20. 抑王兴甲兵，危士臣，构怨于诸侯，然后快于心与。**
**答案：** 还是大王发动战争，使将士危难，与诸侯结怨，然后心里才痛快吗？

**21. 臣奉使使威后，今不问王而先问岁与民，岂先贱而后尊贵者乎。**
**答案：** 我奉命出使到威后这里，现在不先问君王却先问年成和百姓，难道是把卑贱的放前、尊贵的放后吗？

## 四、阅读题

### 31. 阅读《晋灵公不君》，回答问题。

**（1）指出文章的两个判断句。**
**答案：** “董狐，古之良史也。”“赵盾，古之良大夫也。”

**（2）指出文章中的宾语前置句并说明分析。**
**答案：** “莫之继也”即“莫继之”，代词“之”作宾语前置；“其我之谓矣”即“其谓我矣”，“之”是宾语前置标志。

**（3）文章中标点“其”的词性和用法。**
**答案：** “其右提弥明知之”中“其”为代词，他的；“其我之谓矣”中“其”为副词，表推测，大概。

**（4）指出文章三个古字或通假字，并标注出今字。**
**答案：** “辟”通“避”（辟丸）；“真”通“置”（真诸备）；“竟”通“境”（亡不越竟）。

## 五、作文（40分）

**33. 勇敢的人先享受世界，随心而动说走就走。**
**写作思路：**
- 可写勇敢、行动、追求理想与诗意。
- 但也要注意：说走就走需要现实基础，不能完全脱离责任。
- 立意：勇敢不是鲁莽，而是在理性基础上追求心中热爱。
- 可结合“诗与远方”与“人间烟火”的辩证关系。

**参考范文提纲：**
1. 开头：引用材料，提出“勇敢是理想与现实的桥梁”。
2. 论证：勇敢让人突破舒适区，先享受世界。
3. 辩证：随心而动不等于逃避责任，需有准备与担当。
4. 结尾：在人间烟火中守住诗意，在勇敢行动中实现理想。
