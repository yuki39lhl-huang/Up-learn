**账号约定（一期）**
- **邮箱验证码登录**：`email` + 6 位验证码；未注册邮箱验证通过后**自动注册**
- **密码登录**（可选）：需在账号安全中先设置密码（`password_set=1`）；规则 8～32 位且含字母与数字
- **双 Token 登录态**：Access JWT **30 分钟**（`ul.jwt.access-ttl-ms`）+ Refresh 存 Redis **7 天**（`ul.jwt.refresh-ttl-seconds`）；业务 API 只带 Access；过期用 Refresh 换新
- **昵称**：自动注册时服务端默认「升本er + 随机串」；可 `PUT /api/user/info` 修改
- **头像**：自动注册时写入默认 `avatar_url`；可随后修改；**图片文件存阿里云 OSS**（见 §四 OSS）；私有 Bucket 用签名 URL 展示
- 不用用户名、**不收集手机号**（不做短信）

#### 限制滚动区域（考纲页）

目标：侧栏 + 顶栏「考纲查询」+ 卡片头/省年筛选/科目标签**不随正文滚动**；正文标题用科目胶囊展示；**考试范围 / 参考书目正文**独立滚动；切换科目时标签栏不动，正文区滚回顶部。

写法要点（`SyllabusPanel.vue`）：

1. 外层 `module-shell module-shell--fill` + 内层 `module-card module-card--fill`：占满视口剩余高度并 `overflow: hidden`，避免整页与正文双滚动条。
2. 固定区：`module-card__head`、`.syllabus-toolbar`（筛选 +「展开/收起科目」）；科目标签用 `.syllabus-subjects-clip`（`grid-template-rows`）做展开过渡。
3. 标题与 Tab（考试范围 / 参考书目）放在滚动区**之外**（`.syllabus-doc__head` 科目胶囊 + `.syllabus-tabs`）。
4. 仅 `.syllabus-doc__scroll`：`flex: 1; min-height: 0; overflow-y: auto`。
5. 切科后 `docScrollRef.scrollTop = 0`（`loadDetail` 的 `finally`）。
6. 指定篇目 `ol.syllabus-works` 需足够 `padding-left`（约 `2.4em`）；`li` 使用 `:value="work.seq"`。

`--fill` 高度公式与一点通一致：`calc(100vh - var(--gmail-topbar-h) - 56px)`。

院校查询：点击「查看」/目标院校后，`scrollToMajorsPanel` 在控制台滚动容器内定位到开设专业区；换校时保留旧列表遮罩加载，避免闪屏。
